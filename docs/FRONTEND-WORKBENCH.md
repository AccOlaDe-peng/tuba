## 页面和交互

| 工作区 | 实现内容 |
| --- | --- |
| 调查工作台 | 安全总览、真实认证事件趋势、异常列表与证据抽屉、实体目录与风险、实体详情分栏、案件列表与看板、案件工作台与快照/结论 |
| 数据治理 | 事件 SPL 查询、当前会话查询保存、原文/敏感字段权限、导出、来源列表与详情、三步来源注册、一次性凭据、Agent 注册/绑定/组件升级、质量与数据模型目录 |
| 分析运营 | 从发布清单读取分析资产、实体统计基线、反馈与评估结果 |
| 平台管理 | 发布注册/详情/验证/暂存/激活、发布者授权、导出任务与单次下载、运行状态、审计、成员和权限矩阵 |

导航按真实权限显示，直接访问受限路由也受保护。登出清空查询缓存和会话查询。一次性密钥只保留在弹窗组件状态，关闭后清除，写操作的 mutation 缓存不保存密钥响应。

案件编辑遇到版本冲突保留输入并提供显式刷新；Agent 升级合并操作者提供的完整配置，只修改目标组件版本，保留其他来源和组件配置。重复提交相同来源/发布草稿保持同一个幂等键。

## 尚需后端交付的能力

处理任务创建、回放提交、模型训练和完整模型生命周期、备份恢复执行、容量遥测、来源过滤规则编辑、来源暂停和上下文切换、完整规则编辑、独立服务身份清单、案件追加记录以及通知等尚未获得对应可执行 API。相关入口标注限制，写操作禁用；不会显示模拟成功。

实体风险只对当前加载页排序，不宣称全局排行。无风险投影显示缺失状态；来源收据、水位以及容量数据缺失时不生成假指标。普通来源管理员可以输入已批准的发布引用，不额外要求发布读取权限。
