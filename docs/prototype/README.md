# TUBA Web 控制台原型

打开 [`index.html`](index.html) 可查看首版交互原型。该原型用于确认信息架构、页面职责和核心操作，不代表最终视觉稿，也不连接真实 API。

## 页面范围

| 页面 | 路由建议 | 主要用户 | 核心任务 |
| --- | --- | --- | --- |
| 安全总览 | `/overview` | 分析师、租户管理员 | 查看风险、积压、检测新鲜度和重点实体 |
| 异常调查 | `/anomalies` | 分析师 | 筛选、排序、批量分派和进入证据调查 |
| 异常详情 | `/anomalies/:id` | 分析师 | 查看解释、证据时间线、实体上下文并建案 |
| 案件中心 | `/cases` | 分析师 | 跟踪案件状态、优先级、负责人和 SLA |
| 案件详情 | `/cases/:id` | 分析师 | 处置、协作、记录时间线和结案 |
| 数据源 | `/settings/sources` | 租户管理员 | 查看接入状态、质量、过滤和积压 |
| 用户与权限 | `/settings/access` | 租户管理员 | 管理成员、角色和权限范围 |
| 系统运行 | `/operations` | 平台/租户管理员 | 查看 Kafka、ES、分析任务、DLQ 和 SLO |

## 交互原则

- 左侧导航按调查、运营、管理分组；租户选择位于全局顶栏。
- 首页只呈现需要行动的信息，深层平台指标放入系统运行页面。
- 异常详情是调查主入口，证据时间线、解释和实体上下文在同一页面完成。
- 任何状态变更、分派、导出和权限操作都显示权限要求，并产生审计记录。
- 页面中的 tenant、时间范围、筛选条件和分页必须由 Go API 验证；前端不直连 Elasticsearch。

## 原型与正式实现的关系

React 实现建议将页面壳、查询过滤器、风险标签、证据时间线、实体摘要、状态流转和审计时间线拆成独立组件。原型中的数字和事件均为演示数据；正式实现以 OpenAPI 和权限合同为准。
