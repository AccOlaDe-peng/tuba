# M3 控制台验收记录

验收日期：2026-09-24

## 交付范围

- OIDC Authorization Code + PKCE 登录、回调 state 校验、会话失效清理和权限路由。
- 安全总览：开放异常、高危数量、处理中案件、检测新鲜度、今日结案和最近异常。
- 异常调查：严重度、状态、实体筛选，游标增量分页，空状态、错误恢复和请求取消。
- 异常详情：检测解释、实体、风险分数、证据时间线，以及从异常创建关联案件。
- 案件中心：状态和优先级筛选、游标增量分页、新建案件。
- 案件详情：状态流转、指派、判定与结案、重新打开、关联异常和追加式活动时间线。
- 用户与权限：成员角色查看、授予和撤销。
- 系统运行：API、PostgreSQL、Elasticsearch 实时状态和分析结果新鲜度。
- 浏览器不保存数据中间件凭据，所有数据和写入均经过 Go API 合同与权限校验。
